Support

Add a record

Tap + , enter the dish name, date, category, result, and a rating from 1 to 5. Add ingredient lines with an amount and a unit. Empty ingredient rows are dropped when you save.

Ratios and servings

Amounts belong to the serving size you save. On the detail screen, change “Scale to” to see other amounts. When every line uses the same unit, a percentage is shown. “Save these amounts” rewrites the stored quantities.

Cook again

Cook again copies the recipe into a new record dated today and opens it. Cancel deletes that new copy. Save keeps it.

Export

Premium unlocks Markdown, JSON, and CSV. JSON is the backup you can import later, including photos. Import stays free.

iPhone and Mac

Install Cooking Log on both, with the same Apple ID and iCloud on. Records sync through the private database iCloud.com.qzmtree.cookinglog. Use Restore Purchases on the other device to unlock export.

技术支持

添加记录

点 + ，填写菜名、日期、分类、结果，以及 1 到 5 分。材料行写上用量和单位。保存时会丢掉空的材料行。

配比和人份

用量属于你保存的那个人份。详情里改「换算到」可以看其他用量。所有材料单位相同时会显示百分比。「按这个份量改写配料」会改掉已保存的用量。

再做一次

再做一次会复制配方，日期改成今天，并打开这条新记录。取消会删掉这份新副本。保存会留下它。

导出

高级版解锁 Markdown、JSON 和 CSV。JSON 是可以再导入的备份，包含照片。导入保持免费。

iPhone 和 Mac

两台设备都安装菜记，使用同一个已开启 iCloud 的 Apple ID。记录通过私有数据库 iCloud.com.qzmtree.cookinglog 同步。在另一台设备上点恢复购买，即可解锁导出。

邮件 stephenmtree@gmail.com。
