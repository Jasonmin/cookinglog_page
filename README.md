# Cooking Log page

Static privacy, support, terms, and FAQ site for Cooking Log (菜记).

The live site is GitHub Pages:

https://jasonmin.github.io/cookinglog_page

Links are relative so the same files also work at a domain root. If the URL changes, update `AppLegalLinks.websiteBase` and the App Store metadata URLs together.

Remotes: Cursor `https://origin.cursor.com/q-m/cookinglog-page`, GitHub `https://github.com/Jasonmin/cookinglog_page`. Push both with `./scripts/push-mirrors.sh`.
